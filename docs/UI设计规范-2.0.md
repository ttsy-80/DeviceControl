**版本**：2.0.1（修订见 §11；主体仍对应 PDF 2.0 稿）  
**唯一视觉权威**：桌面《电动转动系统app-预览2.4.pdf》（18 页）。  
**对照资产**：`docs/ref-pdf-preview/page-01.png` … `page-18.png`（导出图与 PDF 同步评审）。

## 1. 全局框架（各页共性）

### 1.1 顶栏（PDF 全页）

- **左**：时间 `HH:mm:ss`；日期「星期 + yyyy/MM/dd」。  
- **中**：中英双行标题（随页面：主界面 / 设置 / 发动机检测 / MODEL CATALOG 等）。  
- **右**：可选「返回首页」灰胶囊；**电池图标**；**连接状态胶囊**：未连接红底白字 / 已连接绿底白字。

### 1.2 底栏

- 中文公司名 + **AIWINGS** 英文标（各页保持）。

### 1.3 横屏与触控

- 横屏为主；主按钮与宫格卡片触控目标 **≥ 48dp**（与 Material 一致）。窄屏缩小间距时 **不得** 把可点区域压到 48dp 以下。

## 5. 间距与圆角

- 卡片圆角、按钮圆角与稿面大圆角风格一致时，优先统一到 `dimens.xml`（如 12–16dp 卡片、24–28dp 大按钮）。  
- 三栏比例：建议 **左 22% / 中 48% / 右 30%** 为初值，以 PNG 像素级对齐后固化 `layout_weight` 或 `ConstraintLayout` guideline；**窄屏下的三栏折行策略见 §6**，不得三栏重叠不可点。

## 6. 手机与平板尺寸兼容（响应式）

与 `docs/基础开发-Prompt与规范.md` §4.1 一致，以下为 **UI/布局侧** 可验收条款。

### 6.1 设计原则

- **基准**：大屏横屏与 PDF / `page-*.png` 对齐。  
- **扩展**：手机与小平板通过 **自适应布局 + 可滚动区域** 保证主路径可用，而非简单等比缩小字体到不可读。  
- **实现倾向**：`ConstraintLayout`、`LinearLayout` **权重**、`0dp` + 约束；内容区 **`NestedScrollView` / `RecyclerView`** 承接溢出；避免用 **`px`** 定死整行宽度。

### 6.2 断点与资源

- 使用 **`values-sw600dp`、`values-sw720dp`** 或 **`layout-w600dp`** 等 **smallest width / 最小宽度** 资源，区分手机 / 小平板 / 大平板的 **宫格列数、侧栏宽度、边距**。  
- 复杂页可配合 **`layout-land`**；重复结构优先 **`include` / 自定义 View**，避免两套逻辑漂移。

### 6.3 典型屏型（走查最低要求）

| 类型 | 参考 | 验收要点 |
|------|------|----------|
| 手机窄屏 | 最小宽约 **360dp**（竖屏或产品允许的横屏） | 无关键按钮裁切；标题与状态可读；表体可滚动到达 |
| 平板横屏 | **10" 级**、与 PDF 接近的宽度 | 与稿面分区一致；三栏比例接近 §5 初值 |

### 6.4 三栏页（P7～P12）在窄宽度下的策略

须在设计或实现说明中 **明确选一或组合**（评审写死一种即可）：

- **纵向堆叠**：左栏信息 → 中栏表与控制 → 右栏矩阵，顺序滚动；或  
- **主从布局**：窄屏仅保留中栏 + 抽屉/底部 Sheet 承载左/右栏；或  
- **横向滑动子区**：某一栏内 `HorizontalScrollView`（慎用，优先堆叠/抽屉）。

**禁止**：三栏固定宽度叠加导致 **遮挡、无法点击结束/暂停**。

### 6.5 字体与密度

- 字号、间距用 **`sp` / `dp`**；长文案配合 **`ellipsize`、`maxLines`** 与滚动容器。  
- 多密度下抽检 **mdpi / xhdpi** 或常见真机，避免矢量/位图发动机图比例失调。

## 7. 组件规范

### 7.1 按钮

- **主操作**：Filled，绿/橙/蓝按上表语义。  
- **结束**：禁止与「暂停」同色；需禁用态与按压态。  
- **宫格入口**：整卡可点；选中态浅底边框（见 P6）。

### 7.2 步进器（P8、P11）

- 单行：`[−]` `[数值]` `[+]`；标签左对齐，多行纵向等距。  
- 单位（°/秒、S、片）紧跟数值区或 helper，与需求单位换算说明一致。

### 7.3 表与列表（检测中栏）

- 固定表头 + 可滚动表体；行内「返回」「删除」与稿图标颜色一致（绿/红）。

### 7.4 对话框（P12、P18）

- LPC：列表 maxHeight + 滚动；底部双按钮左右分布。  
- ERROR：顶条通栏红；内容区留白；主按钮destructive 顺序与稿一致。

## 8. 图标与插图

- 发动机示意图位图或矢量与 P7 左栏比例一致；安全扭矩等标签左列对齐。  
- 设置、拍照、方向等图标线宽统一，避免混用填充与线框两套风格。

## 9. 文案与本地化

- 用户可见串统一 `strings.xml`；键名建议带页面前缀如 `home_`、`settings_`、`inspect_`。  
- 公司名、400 电话、AIWINGS 与 PDF 一致；多语言资源随 P3 语言切换加载。
