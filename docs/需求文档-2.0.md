# 发动机电动转动系统 App — 需求文档 2.0

**版本**：2.0  
**需求来源**：以《电动转动系统app-预览2.4.pdf》为唯一权威（共 18 页）；工程内已导出逐页 PNG：`docs/ref-pdf-preview/page-01.png` … `page-18.png` 便于评审对照。

## 1. 产品定位与范围

- **产品名（稿面）**：发动机电动转动系统 / ENGINE ELECTRIC MOTORING SYSTEM。  
- **形态**：横屏平板/工控屏为主；全屏顶栏 + 分区内容 + 底栏品牌。  
- **核心价值**：型号与工位数据管理 → 进入检测主控 → 自动/手动模式转动与记录 → 系统设置与连接状态。

**不在本文展开**：底层 CAN/CiA402 帧级协议（见《技术方案设计-2.0》与代码）。

## 3. 功能需求（按域）

### 3.1 全局顶栏（各页一致）

- **时间**：`HH:mm:ss`；**日期**：星期 + `yyyy/MM/dd`。  
- **标题区**：中英双行标题（随页面变化）。  
- **右区**：`返回首页`（灰胶囊，部分页）；**电池图标**；**连接状态**：`未连接`（红底）/ `已连接`（绿底），与设备/蓝牙状态联动。

### 3.2 主界面（P1）

- **开始检测**：进入检测流程（稿面指向「发动机检测」型号选择页 P6）。  
- **型号管理**：进入型号管理（P13）。  
- **设置**：进入设置体系首屏（稿面为蓝牙连接 P2，或设置总容器待产品定）。

### 3.3 设置域（P2～P5）

- **侧栏菜单**：蓝牙连接、语言、软件更新、关于、操作手册；当前项橙色高亮，其余浅灰。  
- **蓝牙连接**：设备列表（设备001…）；单项选中态（橙胶囊）；**确认连接**。  
- **语言**：多语言单选 + **更改设置**。  
- **系统升级**：展示当前版本、上次检测时间；**检查更新**（需对接升级策略，稿面未写死接口）。  
- **关于我们**：公司文案；**获取帮助** + 400 电话。  
- **返回主界面**：回到 P1。

### 3.4 发动机检测（P6～P12）

- **型号选择（P6）**：宫格展示型号；选中态视觉区分；竖向滚动条；返回首页。  
- **主控台（P7 等）**：  
  - **左栏「引擎信息」**：安全扭矩、叶片数、当前/设定速度、剩余/转动时间、游隙消除、运行时间、电机力矩等（稿面部分为空，需实时刷新规则另表）；发动机示意图。  
  - **状态栏文案**：示例「连续 1.0分钟/圈 反转」— 与模式、速度单位、方向绑定。  
  - **中栏**：模式下拉（**自动模式 / 手动模式**）；工位/LPC 下拉（如 LPC1）；**位置/叶片数/操作** 表；行操作「返回」「删除」；**返回时消除游隙**、**记录**；**开始**（绿）、**暂停**（橙）。  
  - **右栏**：正转/反转、加速/减速、连续/点动、自动拍照、设置；游隙消除及状态检测文案；**结束**（稿面为强提示/红框，语义为结束检测会话或停控，需与硬件安全策略对齐）。  
- **自动模式设置（P8）**：步进器编辑各自动参数；**确认修改** / **返回**。  
- **手动模式设置（P11）**：同上，字段为手动维度。  
- **位置选择（P12）**：弹层列表；**取消** / **选择**；单行选中高亮。

### 3.5 型号管理（P13～P17）

- **型号目录（P13）**：宫格 + **蓝色新增**入口；滚动。  
- **型号详情/编辑（P14～17）**：引擎信息卡、导入图片、明细表 CRUD、编辑/保存/返回；行内编辑时按钮由「添加」切换为「保存」等（以稿为准）。

### 3.6 异常与容错（P18）

- **错误弹窗**：顶条 `ERROR`；标题「操作失败！」；原因区（示例：未连接到设备）。  
- **操作**：**关闭提示**；**回到主界面**。

## 4. 非功能需求

- **横屏**：与稿面一致。  
- **触控**：主按钮、宫格卡片满足工业触控面积。  
- **状态一致性**：顶栏「已连接/未连接」与各业务页禁用/启用策略一致。  
- **品牌**：底栏「北京艾讯飞科技有限公司」「AIWINGS」各页保持。
