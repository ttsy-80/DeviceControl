## 1. 稿面与工程前提

- PDF 以**视觉与信息架构**为主，多数页**未展开状态机、边界条件、数据与安全策略**，属常见情况。

## 2. 不合理或高风险（建议优先评审）

| 编号 | 主题 | 说明 | 建议 |
|------|------|------|------|
| R1 | 「结束」与「暂停」边界 | 若「结束」为强提示（如红框），与「暂停」在停转、会话是否结束、数据是否落库、返回哪一页（P1/P6）上易混淆。 | 明确：结束 = 停转 + 退出检测会话 + 导航目标；暂停 = 仅停转可恢复。 |
| R2 | 「已连接」单一状态 | 蓝牙已配对、USB 已插、协议握手成功、伺服 ready 往往是**不同阶段**；单一绿标易掩盖「连上但不能控」的中间态。 | 分级状态或子文案（如「已连接·未就绪」），或二级详情入口。 |
| R3 | 多维度模式叠加 | 自动/手动、点动/连续、LPC 切换若**无互斥规则**，可能出现非法组合或危险操作顺序。 | 用状态表列出「允许的组合」与切换时电机行为（先减速再切等）。 |
| R4 | 参数步进器多（约 P8、P11） | 项多易误触；无**范围、默认值、运行中是否可改**时，存在误设速度类风险。 | 每项：最小/最大/默认/步进；运行中锁定策略；大变更二次确认。 |
| R5 | 错误弹窗（约 P18）仅「回到主界面」 | 部分失败场景用户更希望**重试/忽略/看日志**，直接回首页会打断流程。 | 按错误类型分支：可重试类给「重试」；致命类再给「回主界面」。 |

## 3. 功能细节缺失（建议补「文字说明页」或追记到需求 2.0）

### 3.1 系统与权限

- 蓝牙扫描与连接、存储（升级包/导入图片）、USB 等涉及的 **Android 权限**与**首次引导**流程。  
- **无网 / 弱网** 时：语言包、手册、检查更新的表现（禁用按钮 vs 提示文案）。

### 3.2 设置域（约 P2～P5）

- **蓝牙**：扫描超时、配对失败、多设备策略、与当前检测会话是否互斥（检测中是否禁止换设备）。  
- **语言（P3）**：切换后是否**立即全局生效**、是否需要重启界面、**未保存表单**是否提示。  
- **系统升级（P4）**：包来源、校验、安装失败与回滚、升级前是否**强制停转**、磁盘空间不足提示。  
- **操作手册**：内置 PDF / 外链 / 离线包；无网时行为。  
- **关于 / 400 电话**：是否调起拨号、平板无 SIM 时的降级。

### 3.3 检测主流程（约 P6～P12）

- **进入检测前**：未连接时是否允许进入 P6/P7，还是仅灰显 + 引导去设置。  
- **记录表**：「删除」「返回」作用对象（单行 / 整次会话 / 仅 UI）；**是否可撤销**；审计需求（操作者、时间）若有则需单列。  
- **自动拍照（约 P7～P10）**：触发条件（每圈、每次记录、LPC 变更等）、存储路径、空间不足、**相机权限**、与记录行的绑定关系。  
- **游隙消除**：与速度/方向/模式的**先后关系**、失败与超时提示、是否可跳过。  
- **LPC 弹层（约 P12）**：运行中切换 LPC 是否允许、是否先停转、选中后是否立即下发硬件。

### 3.4 型号管理（约 P13～P17）

- **删除型号**：是否二次确认、是否允许删除「正被检测引用」的型号、级联删除历史记录还是禁止删除。  
- **导入图片**：格式与大小上限、失败提示、是否压缩、与型号数据的绑定关系。  
- **多用户/多设备**（若未来有）：编辑冲突与保存策略（稿面未涉及时可标为「当前版本范围外」）。

### 3.5 异常与容错（约 P18 + 全局）

- **P18 与 Toast / 内嵌错误条**的关系：哪些错误必须弹层阻断，哪些仅轻提示。  
- **通讯中断**（USB 掉线、蓝牙断）：是否自动暂停、是否允许继续编辑本地参数、重连后是否自动恢复「暂停前状态」。  
- **日志**：现场排障是否需要「导出日志」入口（稿面未必有）。

### 3.6 无障碍与现场环境

- **手套模式 / 最小触控区域**是否在工控场景单独要求（可与 UI 规范中的 48dp 合并说明）。  
- **强光下对比度**是否需单独走查标准（若客户有验收条款）。
